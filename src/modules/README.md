# Dhaqan iyo Suugaan: content review and sources

All Hadraawi content is draft, `PENDING_REVIEW`. A fluent Somali teacher must review spelling, translations, definitions and age suitability; a historian or qualified reviewer should confirm factual details and work classifications. Do not enter `APPROVED` without a named reviewer, date and evidence. The data model in `hadraawi.ts` attaches source IDs and review status to each historical event, biography paragraph, work, vocabulary item and question. General lesson explanations are also unapproved. Corrections should be recorded with original text, reviewer, date, evidence and source before changing the learner text.

Sources consulted 22 November 2026:
- Poetry Translation Centre: https://www.poetrytranslation.org/poet/maxamed-ibraahin-warsame-hadraawi/ — birth region and year, 1973 imprisonment for five years, peace work, Gudgude and Dabo Huwan.
- African Studies Centre Leiden: https://www.ascleiden.nl/content/library-weekly/hadraawi — death 18 August 2022 in Hargeisa, 1973 imprisonment for five years, 2004 peace march and Dabo Huwan.
- Prince Claus Fund: https://princeclausfund.nl/awardees/maxamed-ibraahim-warsame — 2012 award, Daba Huwan and Hooyo as poems and Aqoon iyo Afgarad as a play.

The 1978 release year is an inference from 1973 plus five years. These sources do not independently state an exact release date, so the timeline explicitly labels it approximate and the assessment does not ask for it as a verified fact. Name spellings differ across sources: Maxamed Ibraahin Warsame, Maxamed Ibraahim Warsame, and Mohamed Ibrahim Warsame. Prince Claus Fund uses Daba Huwan; the other two sources use Dabo Huwan. These variations are documented rather than silently combined. Leiden says he died at 79; no exact birthday has been independently established here.

No poem, song or quotation is reproduced. The module uses an original generated illustration of a book rather than a portrait. No native recordings, poetry recordings, cloned voice, or unlicensed media are included. Copyright permission for each future asset must be documented before use.

The Poetry Translation Centre profile identifies its biography as adapted from Prince Claus Fund material, and Leiden cites the Fund. These sources should not be counted as fully independent corroboration. Source links provide context for draft vocabulary and explanatory text; they are not necessarily dictionaries or proof of every definition. A qualified reviewer must verify each educational item.

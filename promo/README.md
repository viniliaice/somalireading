# SomaliReading promotional video project

## Exports

- `out/somalireading-9x16.mp4` — vertical 1080 × 1920, 60 seconds.
- `out/somalireading-16x9.mp4` — horizontal 1920 × 1080, 60 seconds.
- `out/somalireading-15s.mp4` — vertical 1080 × 1920, 15-second cut-down.
- `out/thumbnail-16x9.jpg` and `out/poster-9x16.jpg` — poster / cover stills.
- `subtitles-en.srt` — timed English captions / translations for the Somali-script narration.
- `subtitles-en-15s.srt` — captions for the English scratch narration in the short cut.
- `voiceover-somali.md` — fixed Somali script, scene timing, review and pronunciation notes.
- `audio/temporary-english-voiceover.mp3` — **temporary English scratch narration, not Somali VO**.

The 60-second picture master uses the agreed seven-scene timing and a 20 fps frame rate. Captions are supplied as a separate SRT, not burned in. The videos have music and the English scratch read mixed in. There is no Somali TTS in the available voice system: the temporary voice must not be presented as Somali. Have a fluent Somali speaker record the supplied script, review spelling/pronunciation, then replace the scratch track before final approval or publication. Content remains pending fluent-speaker/teacher review.

## Reproduce

From the repository root, with Python 3, NumPy, Pillow and ffmpeg available:

```sh
python3 promo/src/music.py
python3 promo/src/render.py
python3 promo/src/assemble.py
python3 promo/src/poster.py
```

In this workspace the ffmpeg executable is the `imageio-ffmpeg` binary referenced in `promo/src/render.py` and `promo/src/assemble.py`. Update `FFMPEG` in those files if it lives elsewhere. Rendering takes several minutes on CPU. The render script writes silent base masters (`*-video.mp4`) plus the final audio-muxed exports. `assemble.py` rebuilds all final videos and the standalone scratch narration.

## Edit / timeline

- `timeline.json` is the editable scene order and duration sheet for both the 60s masters and 15s cutdown.
- `src/render.py` contains the scene layouts, typography, colors, screenshot placements, movement, and screen-safe text positioning. Change copy/design there; keep required Somali strings, prices and exact URL intact.
- `src/music.py` is the original synthesized instrumental composition; it uses no samples.
- `src/assemble.py` sets voice/music timing and mix levels. When Somali VO is recorded, replace the `audio/vo-temp/en-*.mp3` inputs and adjust timing/mix as needed.
- `src/poster.py` produces the stills from the CTA composition.
- `assets/site/` contains locally captured screenshots of implemented screens, `assets/fonts/` contains the bundled DejaVu Sans family used by the renderer, and `assets/books/` / `books.json` preserve local storybook data for further editing.
- `capture*.mjs` documents the Playwright capture steps. It captures only this repository's running app; it does not scrape the deployed site.

The screenshots are genuine app screens, not mockups. Review/placeholder footers are cropped from relevant images before compositing; no progression, account creation, payment, testimonials or outcomes are simulated. Pricing is shown exactly as **Website Access $5.99** and **Website Access + Lessons $25**, without billing cadence or discount language. The on-screen address is `https://somalireading.vercel.app/`.
